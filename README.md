## 📦 Установка и запуск

```bash
# Клонировать репозиторий
git clone https://github.com/devalmanu/marvel.git

# Установить зависимости
npm install

# Запустить в режиме разработки
npm start

# Собрать для продакшена
npm run build

# Задеплоить на GitHub Pages
npm run deploy
